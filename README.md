# SoundIsland

Минималистичный десктопный аудиомикшер и плавающий виджет в стиле **Dynamic Island** для Windows 10/11. 

Приложение работает **на 100% локально (Offline)** — без фоновых сетевых запросов, телеметрии, аккаунтов и API-ключей.

## Основные возможности

- **Два режима работы:**
  - **Горизонтальный сайдбар (Dynamic Island):** компактная плавающая «пилюля» поверх всех окон с вращающейся виниловой пластинкой (обложкой трека), пульсирующим кольцом в такт басу, 10-полосным мини-эквалайзером и кнопками управления воспроизведением. Свободно перетаскивается на любой монитор и запоминает свою позицию.
  - **Развёрнутый Bento-микшер:** управление общей громкостью и индивидуальная регулировка звука для каждого запущенного приложения в реальном времени (Live-режим).
- **Интеграция с плеерами Windows (SMTC):** автоматическое получение обложки, названия, исполнителя, длительности трека и управление воспроизведением (Яндекс Музыка, браузеры на базе Chromium, Spotify, системные плееры).
- **Живой FFT-эквалайзер с авто-нормализацией (AGC):** реагирует на системный аудиопоток на любой громкости, автоматически уходит в спящий режим при тишине для экономии ресурсов CPU.
- **Локальная телеметрия ПК:** встроенные Bento-виджеты с часами, временем непрерывной работы системы (Uptime), нагрузкой CPU, свободным местом на дисках и объёмом занятой RAM.
- **Системный трей:** сворачивание в область уведомлений с быстрым меню управления и переключения режимов.

## Технологический стек

- **Платформа:** .NET 8 (C# / WPF)
- **Аудио и спектр:** NAudio (WASAPI CoreAudioApi + WASAPI Loopback Capture + FFT)
- **Медиа-сессии:** Windows Media Control (`Windows.Media.Control` / SMTC)
- **Системные метрики:** Win32 API (`kernel32.dll`, `SystemParameters`)
